# SEO Health Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `Esatto.Umbraco.Backoffice.Seo` 1.0.0 — a Content-section "SEO Health" dashboard that scans every published page (all cultures) server-side, evaluates 32 SEO checks, scores the site, and lists prioritised, explained issues.

**Architecture:** A scan fetches each page over HTTP and reduces it to a serialisable `PageFacts` record (stored per page). Every check is a pure function over a `ScanSnapshot` (all page facts + site probe + link statuses) that returns pass/fail **outcomes**; findings, score and priority are all derived from outcomes at read time, so ignores, re-checks and formula changes never need stored findings. Persistence, settings, page listing and dashboard mirror `Esatto.Umbraco.Backoffice.Accessibility`.

**Tech Stack:** .NET 10, Umbraco 18 (Api.Management + Web.Common), NPoco migrations, AngleSharp, xUnit + NSubstitute, Lit/UUI + Vite + TypeScript client.

**Spec:** `docs/superpowers/specs/2026-11-09-seo-design.md`

## Review Focus

1. **URL equality** — canonical, hreflang, sitemap and link comparisons must treat `HTTPS://Esatto.se/om/` and `https://esatto.se/om` as the same page (scheme/host case, trailing slash, default port, fragment dropped; query kept). → `UrlNormalizerTests` in Task 3.
2. **Non-HTML or odd responses** — a PDF, a 5 MB+ body, a missing/`ISO-8859-1` charset or an empty 200 must not crash the scan; the page gets `status-error`-style failure "not an HTML page" or parsed facts. → `PageParserTests.NonHtml_*`, `Fetcher_CapsBody` in Tasks 3/9.
3. **Redirect loops and long chains** — stop after 10 hops or on a repeated URL, record the chain, mark failed. → `FetcherTests.RedirectLoop_StopsAndReports` in Task 9.
4. **Scheduled scan with relative URLs and no base URL** — scan is not started; Overview shows the reason instead of a run with 100 % failed pages. → `BaseUrlResolverTests.Scheduled_NoBase_ReturnsNull` + `ScanRunnerTests.NoBaseUrl_RecordsMessage` in Tasks 8/10.
5. **Sitemap shapes** — sitemap index files, `.xml.gz`, robots.txt `Sitemap:` on another host, and a sitemap that 404s must each give a sensible result, never an exception. → `SitemapReaderTests` in Task 4, `SiteProberTests` in Task 9.
